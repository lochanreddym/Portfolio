# Project Evidence Checklist

Mark items as they are added. Do not invent values to clear checkboxes.

Legend: `[ ]` missing · `[x]` complete · `N/A` not applicable

---

## Shared requirements (every project)

- [ ] Confirmed project dates
- [ ] Confirmed data classification
- [ ] Dataset name + source link (or synthetic label)
- [ ] Cover image with descriptive alt
- [ ] At least 2 gallery evidence figures
- [ ] At least one method artifact (SQL / Python / DAX / Excel / model)
- [ ] Findings written from real analysis
- [ ] Recommendations tied to findings
- [ ] Limitations stated
- [ ] External links only when real (never `#`)
- [ ] Verified results populated only with real metrics (else leave null)
